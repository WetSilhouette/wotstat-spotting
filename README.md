# WotStat Spotting

Мод для отображения зон засвета собственной техники — 6 точек засвета
и 2 порта дальности обзора, реально используемых игровой механикой
маскировки — в виде наложения прямо в игровом мире, а также подсказок
по угловой экспозиции относительно ориентации собственного корпуса.
Обучающий инструмент по позиционированию и углованию — в том же духе,
что и просмотрщик брони, только для механики засвета.


## Установка

Релиз пока не опубликован. Соберите мод из исходников:

1. Склонируйте репозиторий.
2. Выполните `./build.sh -v <версия> -d` (подробности — в разделе
   Build Commands файла `AGENTS.md`; нужен Python 2).
3. Скопируйте получившийся `wotstat.spotting_<версия>.mtmod` в папку
   `Tanki/mods/{АКТУАЛЬНАЯ_ВЕРСИЯ_ИГРЫ}/`.

Когда появится релиз, он будет опубликован на странице
[GitHub Releases](https://github.com/WetSilhouette/wotstat-spotting/releases/latest).

## Использование

- `F4` - Показать/Скрыть оверлей засвета.
- `F5` - Показать/Скрыть подписи точек засвета и портов (по умолчанию
  выключено — обычно достаточно одних цветов).

### Значение маркеров

**Точки засвета** (6 маленьких сфер) — окрашены по угловой экспозиции
относительно текущего направления *вашего собственного* корпуса. Это
эвристическая, декоративная подсказка, а не предсказание того, видит
ли вас конкретный противник прямо сейчас — она никогда не использует и
не требует никаких данных о противниках:

- `Оранжевый` - лицевая сторона (в пределах ~45° от направления
  корпуса вперёд).
- `Жёлтый` - борт.
- `Зелёный` - корма.

**Порты дальности обзора** (2 сферы побольше):

- `Красный` - порт шасси. Статичен и привязан к корпусу — всегда
  находится в самой высокой точке коллизии танка.
- `Пурпурный` - порт башни. Единственный из 8 маркеров, который
  отслеживает вращение башни в реальном времени; все 6 точек засвета и
  порт шасси жёстко привязаны к корпусу даже при повороте башни.

## Чего этот мод никогда не будет делать

- **Никаких данных о технике противника в любом виде** — ни точек
  засвета, ни портов обзора для какой-либо техники кроме своей,
  засвеченной или нет, никогда, ни под каким переключателем или
  «отладочным» предлогом.
- **Никакого предсказания в реальном времени «засвечен ли я прямо
  сейчас конкретным противником».** Сервер никогда не передаёт клиенту
  позицию незасвеченного противника, поэтому легитимного источника
  данных для этого не существует.
